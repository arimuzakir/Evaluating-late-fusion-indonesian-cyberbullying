# Methods and reproducibility

## 1. Cohorts and evaluation design

The frozen `v1.1-GoldAdjudicated` label inventory contains 13,307 observations: 8,906 standalone text comments and 4,401 ten-second video windows (segmented with a 10 s window and 3 s stride from 233 source videos). The multimodal alignment filter retains **3,951** video windows across **214** linked source groups. The remaining **450** windows lack aligned multimodal views (`missing_video_file = 359`, `missing_keyframe_image = 91`; see `results/statistics/revision_20261108/exclusions/EXCLUSION_REASON_PLATFORM_CLASS.csv`) and no model accuracy is imputed for them. The high-agreement standalone-comment benchmark retains **8,196** comments (`1,226` held-out test). The two tracks are evaluated independently and are never pooled into a single accuracy metric.

In the primary video evaluation (`results/video/gold_adjudicated_v1.1/`), source groups are partitioned into four source-disjoint outer folds (`fold 0..3`) and five mutually disjoint roles within each fold (`fit`, `early_stop`, `meta_fit`, `calibration`, `test`), repeated across three training seeds (`42, 2026, 2027`). Per-fold and per-seed window and source-group counts are tabulated in `results/video/revision_20261108/roles/ROLE_COUNTS.csv`, and the role usage of all 21 primary configurations plus the 2 seed-42 revision probability controls is documented in `results/video/revision_20261108/roles/MODEL_ROLE_RULES.csv`.

When both OCR and STT outputs are empty (`685` of `3,951` aligned windows), extracted-text branches emit the neutral fallback probability `p = 0.5`. Because the positivity rule is strict (`p > τ*`), `p = 0.5` yields a positive prediction whenever the validation-selected threshold `τ* < 0.5` and a negative prediction whenever `τ* >= 0.5`. Exact fallback confusion counts across all seeds and calibration controls are archived in `results/statistics/revision_20261108/fallback/NO_TEXT_FALLBACK.csv`, `TEXT_FALLBACK_DECISIONS.csv`, and `CALIBRATION_CONTROL_FALLBACK.csv`.

## 2. Primary inference, estimand hierarchy, and retrospective MDE

The focal seed-42 contrast compares `equal_vat` against `text` on all 3,951 held-out video windows, resampling or permuting all windows within each of the 214 source groups together (`100,000` replicates in `results/statistics/FOCAL_FOUR_100000.csv`):
- **Window-weighted Macro F1 (primary estimand)**: `equal_vat = 0.5669796`, `text = 0.5703419`, `Δ = −0.0033623`, 95% clustered bootstrap CI `[−0.0178766, +0.0115901]`, paired clustered permutation `p = 0.6607534` (`p_holm = 1.0`).
- **Source-weighted Macro F1 (cluster-size sensitivity estimand)**: Equal-source weighting weights each of the 214 source groups by `1 / (214 × n_g)` (`equal_vat = 0.5829024`, `text = 0.5877746`, `Δ = −0.0048723`; see `results/statistics/revision_20261108/main_result_checks/TABLE3_RECOMPUTED.csv` and `results/statistics/revision_20261108/probability/TABLE6_PROBABILITY_METRICS.csv`). Designating window-weighted metrics as primary and source-weighted metrics as sensitivity was a **revision-time reporting decision**, not a preregistered analysis plan.
- **Retrospective minimum detectable effect (MDE)**: From the empirical clustered bootstrap standard error (`SE = 0.0075125`), the two-sided `α = 0.05`, 80%-power retrospective MDE is `0.0210469` Macro F1 (`0.0247206` after 4-contrast Bonferroni adjustment; see `docs/provenance/revision_20261108/RETROSPECTIVE_MDE.json`). This retrospective calculation is a diagnostic of precision, not a prospective sample-size justification.

## 3. Reviewer-requested V4 sensitivity and control analyses

1. **Two additional main-pipeline source-group allocations (`R2.5`)**:
   To evaluate sensitivity to the outer 4-fold source-group assignment beyond frozen-feature linear probes, the full main pipeline (all 21 models plus 2 probability controls) was executed at training seed `42` across two new source-disjoint outer partitions (`results/video/revision_20261108/source_partitions/`):
   - **Partition `1042`** (`search_start_seed = 1042`, `effective_outer_seed = 1042`, training seed `42`): `text = 0.556713`, `equal_vat = 0.572011`, `Δ = +0.015298` (`95% CI [−0.002975, +0.033560]`).
   - **Partition `2042`** (`search_start_seed = 2042`, `effective_outer_seed = 2044`—the first candidate seed from `2042` satisfying fold-balance tolerance—with training seed `42`): `text = 0.583194`, `equal_vat = 0.577858`, `Δ = −0.005336` (`95% CI [−0.023532, +0.012642]`).
   Pooled across the baseline (`42`) and two new outer allocations (`1042`, `2042`), mean `Δ(Equal VAT − Text)` is `+0.002200` (`SD = 0.011386`, range `[−0.005336, +0.015298]`).
2. **Neural-head 2×3×2 factorial sensitivity and runtime reconciliation (`R1.2`)**:
   Across 48 seed-42 runs (`weight_decay ∈ {1e-4, 1e-3}`, `dropout ∈ {0.1, 0.2, 0.3}`, `head_lr ∈ {5e-4, 1e-3}`) for `visual_linear`, `audio_mlp`, `feature_mlp`, and `healnet` (`results/video/revision_20261108/head_sensitivity/`), Macro F1 remains within narrow bands (`visual_linear: 0.4648–0.4910`, `audio_mlp: 0.4980–0.5177`, `feature_mlp: 0.5333–0.5608`, `healnet: 0.5327–0.5568`). `HEAD_BASELINE_RECONCILIATION.csv` documents why the matched cell `(1e-4, 0.2, 1e-3)` differs slightly from frozen Table 3 (`Δ Macro F1` between `-0.0126` and `+0.0040`): the original `GoldAdjudicated v1.1` training set `torch.set_float32_matmul_precision('high')` on an NVIDIA A100 GPU, whereas the sensitivity grid was run in a separate session where that flag was not recorded. Primary Table 3 retains the frozen `v1.1` numbers unchanged.
3. **Seed-42 probability controls (`R1.4`)**:
   Two additional post-hoc fusion controls—out-of-fold Platt/sigmoid-calibrated equal average (`sigmoid_equal_vat`, fit on `calibration`) and simplex-constrained probability-space linear combination (`convex_vat`, fit on `meta_fit` with `w >= 0, sum(w) = 1`)—are archived in `results/statistics/revision_20261108/probability/CALIBRATION_CONTROL_TEST_PREDICTIONS.csv` and `TABLE6_PROBABILITY_METRICS.csv`. Both controls are available for **seed 42 only**. While `sigmoid_equal_vat` reduces window-weighted Brier score (`0.23370` vs `0.28298` for `text`, `Δ Brier = −0.04928`, 95% CI `[−0.06808, −0.02993]`), thresholded Macro F1 (`0.56213`) does not exceed `text` (`0.57034`).
