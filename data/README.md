# Data

`labels/v1_1_GoldAdjudicated/` contains versioned labels, source records, votes and role manifests in a **redacted public numeric view**. `annotation_sources/` preserves five recorded binary votes by pseudonymous master ID. `manifests/comments/` records the independent high-agreement comment benchmark split. `features/` contains numerical frozen embeddings and waveform16 arrays with their recorded provenance. No original post text, URLs or raw audio/video content should be redistributed from this release. See [data governance](../docs/data_release.md).
