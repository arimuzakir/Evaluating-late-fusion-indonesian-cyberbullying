# Figures

This directory contains the manuscript schematic diagrams (`Fig_1.png`, `Fig_2.png`) and the statistical/empirical illustrations generated deterministically from the frozen **v1.1-GoldAdjudicated** and **V4 revision** result tables by `python scripts/analysis/make_figures.py`.

## Manuscript schematic diagrams
- `Fig_1.png`: **Figure 1** — Five-stage data acquisition, initial ratings (5 annotators, Fleiss `κ = 0.8853`), expert review and adjudication (`κ = 0.8851`, `0.8954`, and 100-window input audit `κ = 0.8998`), master corpus `Gold v1.1` (`13,307` records), and evaluation populations (`8,196` standalone comments + `3,951` aligned video windows across `214` source groups and `450` alignment exclusions).
- `Fig_2.png`: **Figure 2** — Modality-specific branches (`Visual: EfficientNet-B0`, `Acoustic: 16 features`, `Text: IndoBERT-base-p2`), late-fusion and comparison configurations (`Equal VAT`, pair averages, logistic stacking, feature concat MLP, HEALNet adaptation, frozen `SigLIP 2` probes), and source-disjoint 4-fold, 5-role evaluation protocol.

## Empirical figures regenerated by `scripts/analysis/make_figures.py`
- `comment_benchmark_macro_f1.png`: Standalone comment benchmark held-out Macro F1 (`n = 1,226`, seed 42).
- `video_three_seed_stability.png`: Aligned video-window Macro F1 means and SD across three training seeds (`42, 2026, 2027`).
- `video_confusion_matrices_seed42.png`: Paired seed-42 confusion matrices for Extracted Text and Equal VAT (`n = 3,951`).
- `focal_paired_difference_seed42.png`: Focal seed-42 paired Macro F1 contrast and 100,000-replicate clustered 95% bootstrap CI (`214` source groups).
- `revision_20261108/reliability_*.png`: Publication-formatted (`>10pt`, 300 DPI, borderless) window-weighted and source-weighted reliability curves for seed-42 primary and Table 6 probability-control models. Archived V4 PNGs in `results/statistics/revision_20261108/probability/` remain untouched.
