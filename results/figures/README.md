# Figures

This directory contains the manuscript workflow diagrams (`Fig_1.png`, `Fig_2.png`), the final composite manuscript figures (`manuscript/Fig_3.png` through `manuscript/Fig_6.png` generated by `scripts/analysis/build_manuscript_artifacts.py`), and individual statistical plots generated by `scripts/analysis/make_figures.py`.

## Manuscript schematic diagrams (manual author diagram exports)
- `Fig_1.png` (SHA-256 `5a2145c99127310215df17553f24f2219658355e883e609269a41a742cfa069e`): **Figure 1** — Five-stage data acquisition, initial ratings (5 annotators, Fleiss `κ = 0.8853`), expert review and adjudication (`κ = 0.8851`, `0.8954`, and 100-window input audit `κ = 0.8998`), master corpus `Gold v1.1` (`13,307` records), and evaluation populations (`8,196` standalone comments + `3,951` aligned video windows across `214` source groups and `450` alignment exclusions).
- `Fig_2.png` (SHA-256 `eeae9d409efe2b264068562c5e35f3d65260920236f2386e719ebfef13f693c1`): **Figure 2** — Modality-specific branches (`Visual: EfficientNet-B0`, `Acoustic: 16 features`, `Text: IndoBERT-base-p2`), late-fusion and comparison configurations (`Equal VAT`, pair averages, logistic stacking, feature concat MLP, HEALNet adaptation, frozen `SigLIP 2` probes), and source-disjoint 4-fold, 5-role evaluation protocol.

> **Provenance note:** `Fig_1.png` and `Fig_2.png` are manual author diagram exports; their editable Draw.io source files are maintained outside the public repository in the author's local manuscript working folder and are not publicly distributed. `src/evaluate_release.py`, `scripts/validation/verify_revision.py`, and `scripts/validation/verify_manuscript_artifacts.py` verify the cohort/role counts and SHA-256 digests of these PNG files.

## Composite manuscript figures (`results/figures/manuscript/`)
Regenerated deterministically via `python scripts/analysis/build_manuscript_artifacts.py --root . --write-repo-figures`:
- `manuscript/Fig_3.png`: **Figure 3** — Held-out comment benchmark metrics (`n = 1,226`, seed 42) and Equal Text Ensemble Macro F1 by platform.
- `manuscript/Fig_4.png`: **Figure 4** — Seed-42 OOF confusion matrices for Extracted Text (`Macro F1 = 0.5703`) and Equal VAT (`Macro F1 = 0.5670`) across `3,951` aligned windows.
- `manuscript/Fig_5.png`: **Figure 5** — Focal four paired source-group contrasts (`100,000` replicates, Holm-adjusted `p`-values) and three-seed stability (`Mean ± SD`).
- `manuscript/Fig_6.png`: **Figure 6** — Equal VAT minus Extracted Text across OCR/STT availability states (`10,000` replicates) and effect of fixed (`0.50`) vs. selected decision thresholds.
