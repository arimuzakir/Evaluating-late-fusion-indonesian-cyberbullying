# Recorded input-fidelity audit

This directory includes redacted numerical views of R1 and R2 scores, the recorded adjudication table, OCR/STT fidelity summaries and the item-level keyframe score trace.

`KEYFRAME_ITEM_LEVEL_RECONCILIATION.csv` and `KEYFRAME_RECONCILIATION_STATUS.json` are **derived summaries**, not replacements for the human ratings. The reproducible result for 55 positive audited windows is **46/9/0** for scores 2/1/0. A conflicting earlier coordinator aggregate is preserved for provenance, is not used for reporting, and has not been independently human re-adjudicated. See [`docs/input_audit.md`](../../docs/input_audit.md).
