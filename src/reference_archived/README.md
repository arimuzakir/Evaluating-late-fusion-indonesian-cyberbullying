# Archived Training and Model Reference Code

This folder provides cleaned, non-interactive reference snapshots of the historical GPU training, neural-head sensitivity (`R1.3`), and two-partition focal source-group allocation (`R2.5`) routines extracted from the archived revision notebook (`12_Reviewer_Requested_Only_Colab_V4_EXECUTED.ipynb`, SHA-256 `90ce402df35711f663f71d911380f4bb2936612fdfd87e0fe6f4d2d2e1783fcc`) and the embedded primary evaluation cells (`GOLD_CODE_CELLS.txt` from `08-Pipeline_Multimodal_Video_Evaluasi_GoldAdjudicated_v1_1.ipynb`, SHA-256 `b231e720e6b2015f19b2c3e3847e4c7f4eafbed24762d75f4c0aaec485e3f7ca`). Full SHA-256 lineage and historical file locations are documented in [`../../docs/provenance/revision_20261108/ARCHIVED_CODE_LINEAGE.json`](../../docs/provenance/revision_20261108/ARCHIVED_CODE_LINEAGE.json).
