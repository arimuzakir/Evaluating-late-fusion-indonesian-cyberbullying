# Archived Training and Model Reference Code

This folder provides cleaned, non-interactive reference snapshots of the historical GPU training, neural-head sensitivity, and source-group repartition routines extracted from the archived revision notebook (`12_INASS_Reviewer_Revisions_CPU.ipynb`, which embeds `v1_1_gold_adjudicated_Model.py`). Full SHA-256 lineage and historical file locations are documented in [`../../docs/provenance/revision_20261108/ARCHIVED_CODE_LINEAGE.json`](../../docs/provenance/revision_20261108/ARCHIVED_CODE_LINEAGE.json).

## Reproduction Levels and Scope Boundaries

| Reproduction level | What is computed | Required inputs | Publicly executable in this repository? | Command / entry point |
| :--- | :--- | :--- | :--- | :--- |
| **Level 1 — Saved-prediction & statistical recalculation (CPU)** | All 27 baseline checks, keyframe item-level reconciliation, 100,000-replicate focal bootstrap/permutation inference, MDE diagnostics, 21-model × 3-seed no-text fallback confusion matrices, neural-head pooled & per-fold sensitivity metrics, 2 additional source-group partition effects (`2041`, `2042` with effective outer seed `2044`), 100-window SRSWOR sampling replay & conservative Bonferroni-hypergeometric bounds, and seed-42 calibration/convex probability controls (`Table 6`, Brier intervals, reliability bins). | Public CSV/JSON/NPY artifacts in `data/` and `results/` | **Yes (100% on CPU)** | `python scripts/validation/verify_release.py --root . --full`<br/>`python scripts/analysis/reproduce_revision.py --root . --output /tmp/rev_out`<br/>`python scripts/validation/verify_revision.py --root .` |
| **Level 2 — Frozen-feature probe refitting (CPU)** | Cross-platform LOPO linear probes (20 contrasts, 20,000 bootstrap draws) and 5-seed source-group partition probes on frozen SigLIP 2 (`768D` visual, `768D` text) + `waveform16_v1` (`16D` acoustic) features. | `data/features/siglip2/siglip2_frozen_features.npz`, `data/features/waveform16_v1/audio_waveform16_aligned_3951.npy`, `VIDEO_PRIMARY_MANIFEST.csv` | **Yes (100% on CPU)** | `python scripts/analysis/lopo_cluster_intervals.py --root .`<br/>`python scripts/analysis/repeated_group_probe.py --root .` |
| **Level 3 — Neural-head refitting from cached branch embeddings or end-to-end encoder retraining (GPU)** | Refitting `concat_mlp` and `healnet_adapted_2024` over the 2 × 3 × 2 epoch/weight-decay grid (`48` fits), or retraining `indobenchmark/indobert-base-p2` and `EfficientNet-B0` across new source partitions (`2041`, `2042`). | Restricted unredacted OCR/STT text, restricted extracted video keyframes (`FRAME_CACHE_3996.zip`), or restricted per-fold branch embedding caches (`outputs.npz`) and GPU runtime (`L4`/`T4`). | **No (reference specification only; restricted media/text withheld for privacy)** | Documented in [`model_and_fusion_reference.py`](model_and_fusion_reference.py); all resulting predictions and role manifests are archived and verified under `results/video/revision_20261108/`. |
