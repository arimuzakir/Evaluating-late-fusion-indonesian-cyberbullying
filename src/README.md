# Source utilities and archived reference code

- `src/evaluate_release.py`: Independently recalculates primary stored metrics (`27/27` checks), label lineage links, role separation, and LOPO scores from the frozen `v1.1-GoldAdjudicated` numerical files. Usage: `python -m src.evaluate_release --root .`.
- `src/annotation.py`, `src/audio.py`, and `src/utils/`: Auxiliary annotation agreement, `waveform16` feature extraction, and metric utilities.
- `src/reference_archived/`: Path-sanitized reference copy of the historical model definitions (`FeatureFusion` for `concat_mlp` and `healnet`, `train_transformer` for `indobenchmark/indobert-base-p2`, `train_visual` for `EfficientNet-B0`, and `fit_lr` for `waveform16_v1` logistic regression), 5-role source-disjoint split search (`allocations`), neural-head 2×3×2 sensitivity loop (`sensitivity`: `concat_mlp` and `healnet` across epochs `{15, 30, 60}` and weight decays `{0.01, 0.1}`), and main-pipeline focal (`text` vs `equal_vat`) source repartition driver (`repartition`: partitions `1042` and `2042` [effective outer seed `2044`] at `training_seed = 42`). See [`src/reference_archived/README.md`](reference_archived/README.md) and [`docs/provenance/revision_20261108/ARCHIVED_CODE_LINEAGE.json`](../docs/provenance/revision_20261108/ARCHIVED_CODE_LINEAGE.json) for the three-level reproduction boundaries.
